# Signal Bloom

Signal Bloom is a cooperative two-player constellation-matching game created for the Handshake AI Skills Studio x OpenAI Multiplayer Game Challenge.

## Play

Open `index.html` in a browser. Players take turns revealing hidden stars. Match two signals of the same color to awaken a bloom; awaken three blooms before the solar wind runs out.

The build is intentionally dependency-free so it can be shared as a static project link. The room-code panel and two-player crew UI frame the experience for a future synchronized backend while the current game is fully playable as a hot-seat demo.
