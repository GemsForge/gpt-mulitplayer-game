# Wardrobe prototype references

These concept sheets define the approved visual direction for the first
Blender wardrobe pass. They are design references, not production-ready game
models.

- `wardrobe-tops.png` — flannel, black button-up, quarter zip, graphic tee,
  hoodie, and fitted ribbed-knit polo
- `wardrobe-bottoms.png` — straight-leg jeans, tailored slacks, cargo shorts,
  and pleated wide-leg trousers
- `wardrobe-footwear.png` — two-strap sandals, canvas high-tops,
  maximal-cushion running shoes, leather dress shoes, and flip-flops

The garments are intentionally unbranded and should be adapted to the
feminine, masculine, and nonbinary avatar bases during modeling.
